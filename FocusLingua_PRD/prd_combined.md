# 📘 FocusLingua | 專為注意力不集中與學習障礙者設計的英語學習產品規格書 (PRD)

> **專案代號**：FocusLingua  
> **文件版本**：v1.1.0  
> **目標受眾**：ADHD（注意力不足過動症）、ADD、學習障礙（如閱讀障礙 Dyslexia）及短暫注意力學習者  

---

## 🗂️ 產品規模書六大細項規劃

本產品規劃完全遵循以下六大維度進行設計與細化，以解決學習障礙者需付出多倍精力的痛點：

### 1. 產品定義書 (Product Definition)
* **一句話講清楚**：為誰、解決什麼問題。
* **定義**：專為注意力不集中 (ADHD) 及閱讀障礙 (Dyslexia) 學習者設計的「90秒微感官英語學習應用程式」。利用視覺字型優化、聽覺減壓背景音及觸覺多巴胺即時反饋，解決目標受眾在傳統學習中容易焦慮、分心及認知負荷過載的痛點。

### 2. User Story
* **從使用者角度**：他想做什麼、為了什麼。
* **故事 1 (ADHD 學習者)**：作為一名注意力易分散的成人，我希望每次學習單元控制在 90 秒內且有視覺化計時，使我不會因為課程過長而產生焦慮或直接放棄。
* **故事 2 (閱讀障礙學生)**：作為一名閱讀障礙學生，我希望網頁能切換為 OpenDyslexic 字型與可調間距，讓我能清晰辨識單字字母而不跳行。
* **故事 3 (特教輔導員/家長)**：作為一名家長，我希望查看孩子的專注度反應時間分析，以便瞭解何種學習刺激（視覺/聽覺）對他最有效。

### 3. 功能規格表 (Functional Specifications)
* **可執行功能、規則、優先度**：
  * **P0 - 90s 沙漏計時器**：強制限制學習單元在 90 秒內結束，提供即時進度條。
  * **P0 - Dyslexic 友善設定**：支援 OpenDyslexic 字型切換、字距放大及高對比配色。
  * **P0 - 觸覺多巴胺反饋**：答對時觸發物理震動（行動裝置）與粒子特效（網頁端），給予即時大腦刺激。
  * **P1 - 減壓專注背景音 (BGM)**：整合 40Hz 雙耳節拍、粉紅噪音與白噪音，阻絕環境噪音干擾。
  * **P1 - 專注度自我適應系統**：若使用者點擊延遲 (Latency) 異常拉長，系統自動調降難度並給予提示。

### 4. 架構圖 & 資料模型 (Architecture & Data Model)
* **三層怎麼分工，資料結構長什麼樣**：
  * **前端展示層 (Client)**：React / HTML5 靜態單頁應用，負責無延遲的視覺粒子渲染與 BGM 音訊播放。
  * **中間伺服器層 (API/Server)**：輕量化 API Gateway 連接學習進度與專注力分析引擎。
  * **後端資料層 (DB)**：使用 PostgreSQL 儲存使用者設定與通關進度；使用 ClickHouse 串流紀錄專注時長與點擊 Latency。

### 5. 狀態流 & 畫面示意 (State Flows & UI Mockups)
* **狀態怎麼流動，每頁大概長什麼樣**：
  * **流動狀態**：`開啟應用 (Idle)` ➡️ `載入關卡與背景音 (Loading)` ➡️ `進行 90s 限時挑戰 (Focus Active)` ➡️ `單字呈現 (Word Show)` ➡️ `拖曳/連線互動 (Interaction)` ➡️ `多巴胺勝利慶賀 (Celebration)`。
  * **基本頁面結構**：
    * **主頁面 (Dashboard)**：極簡無干擾設計，僅有一個顯眼的「開始專注」按鈕與歷史專注曲線。
    * **學習艙 (Focus Room)**：上方為 90s 沙漏進度條，中央為 Dyslexic 字型單字卡，下方為白噪音開關。
    * **獎勵彈出視窗 (Reward Modal)**：成功通關時大面積灑花，並顯示「連續專注天數」勳章。

### 6. 素材清單 (Asset Inventory)
* **資料與內容從哪裡來、怎麼整理**：
  * **視覺素材**：
    * `OpenDyslexic-Regular.ttf`（開源閱讀障礙字型，從 OpenDyslexic 官網導入）
    * 慶賀灑花 Lottie 動畫或 HTML5 Canvas 粒子引擎。
  * **音訊素材**：
    * `success_pop.wav`（極簡高頻點擊回饋音效，採自減壓音效庫）
    * `binaural_40hz_focus.mp3`（40Hz 專注波形，由訊號產生器生成並無縫循環）
  * **觸覺素材**：
    * 支援 W3C Vibrator API 與 iOS CoreHaptics 之震動特徵設定檔。
