Item 01

產品定義書 (Product Definition)

專為注意力不集中 (ADHD) 及閱讀障礙 (Dyslexia) 學習者設計的「90秒微感官英語學習應用程式」。利用視覺字型優化、聽覺減壓背景音及觸覺多巴胺即時反饋，解決目標受眾在傳統學習中容易焦慮、分心及認知負荷過載的痛點。

核心受眾痛點分析：

  • 認知負荷過載：市面上英語軟體（如 Duolingo）關卡時間過長（5-15分鐘），對 ADHD 而言，前 3 分鐘後即進入分心期。
  • 文字排版不友善：傳統密集字體與大量單色段落容易引起閱讀障礙者跳行、漏字，導致挫折感加倍。
  • 反饋延遲：缺乏即時、連續且適度的「多巴胺反饋機制」，學習進度停滯時極易放棄。
  • 學習效率不對等：學習障礙者平均需要花費普通人 2 倍以上的精力與重複次數才能內化相同的單字量。

Item 02

使用者故事 (User Story)

從使用者角度出發，我們界定了以下核心情境與驗收標準：

故事 1 (ADHD 學習者)：
作為一名注意力易分散的成人，我希望每次學習單元控制在 90 秒內且有視覺化計時，使我不會因為課程過長而產生焦慮或直接放棄。

故事 2 (閱讀障礙學生)：
作為一名閱讀障礙學生，我希望網頁能切換為 OpenDyslexic 字型與可調間距，讓我能清晰辨識單字字母而不跳行。

故事 3 (特教輔導員/家長)：
作為一名家長，我希望查看孩子的專注度反應時間分析，以便瞭解何種學習刺激對他最有效。

Item 03

功能規格表 (Functional Specifications)

把故事拆成可執行的功能、規劃與優先度：

  • P0 - 90s 沙漏計時器：強制限制學習單元在 90 秒內結束，提供即時進度條。
  • P0 - Dyslexic 友善設定：支援 OpenDyslexic 字型切換、字距放大及高對比配色。
  • P0 - 觸覺多巴胺反饋：答對時觸發物理震動（行動裝置）與粒子特效（網頁端），給予即時大腦刺激。
  • P1 - 減壓專注背景音 (BGM)：整合 40Hz 雙耳節拍、粉紅噪音與白噪音，阻絕環境噪音干擾。
  • P1 - 專注度自我適應系統：若使用者點擊延遲 (Latency) 異常拉長，系統自動調降難度並給予提示。

Item 04

架構與資料模型 (Architecture & Data)

三層分工分立設計：

  • 前端展示層 (Client)：極簡 Web 單頁面應用，使用 HTML5/CSS 變數以及 HTML5 Audio + Canvas 實現極致流暢、無延遲的即時感官反饋。
  • 中間伺服器層 (API/Server)：Node.js API Gateway 與專注力曲線分析模組，將點擊延遲與錯誤率轉化為專注指數。
  • 後端資料層 (Database)：使用 PostgreSQL 記錄使用者設定與通關進度；ClickHouse 串流寫入點擊 Latency 與學習時長。

Item 05

狀態流與畫面示意 (State Flow & UI Mockups)

狀態流動流程：開啟 App (Idle) ➡️ 載入關卡與背景音 (Loading) ➡️ 進行 90s 限時挑戰 (Focus Active) ➡️ 單字呈現 (Word Show) ➡️ 拖曳/連線互動 (Interaction) ➡️ 多巴胺勝利慶賀 (Celebration)。

Item 06

素材清單 (Asset Inventory)

本專案包含以下多感官多媒體素材，以保障學習障礙者的感官協作：

  • 視覺素材：
    • OpenDyslexic 字型檔 (開源下載自 OpenDyslexic 官網，放置於 /assets/fonts/)。
    • 物理碰撞粒子特效檔 (基於 HTML5 Canvas 動態渲染)。
  • 聽覺素材：
    • 40Hz 專注波形音檔 (由音訊合成器生成並設定為 seamless loop 格式)。
    • success_pop.wav 啵啵回饋聲 (採集自 ASMR 減壓音效庫)。
  • 觸覺素材：
    • 裝置微幅震動設定檔 (對應 W3C Vibrator API)。
